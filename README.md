# 🎵 Terminal Music Player

A simple terminal-based music player built using **Node.js** and **VLC**.

Play and control local songs directly from the terminal using keyboard controls.

---

## ✨ Features

* 🎵 Play songs from the `songs` folder
* ⬆️⬇️ Navigate through songs
* ▶️ Play selected song
* ⏸️ Pause / Resume
* ⏭️ Next song
* ⏮️ Previous song
* 🛑 Stop and exit
* 🔄 Stops the previous song before playing another

---

## 🎮 Controls

| Key        | Action         |
| ---------- | -------------- |
| `↑ / ↓`    | Select song    |
| `Enter`    | Play           |
| `Space`    | Pause / Resume |
| `N`        | Next           |
| `P`        | Previous       |
| `Ctrl + C` | Stop & Exit    |

---
